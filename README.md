# 问渠 WenQu · 全网聚合 AI 搜索助手

> 「问渠那得清如许，为有源头活水来。」

问渠是一款 **100% 开源** 的安卓搜索问答应用。它不内置体积庞大的本地大模型，也不依赖任何闭源云服务——而是实时调动 **14 路搜索引擎** 并行抓取、交叉验证、整理成精准简洁的回答。

## 核心特性

- **全网并行搜索**：必应 / 必应中国 / 百度 / 搜狗 / 360 / 神马 / 头条 / 抖音 / 秘塔AI / DuckDuckGo / Mojeek / SearXNG / Brave / 维基百科，全部同时开查，谁被限额就自动跳过，其余引擎照常工作。
- **智能意图识别**：说「你好」「在干嘛」会像人一样动态回复，而不是去搜一堆不相关的资讯；问时间/天气/计算直接本地秒答（全球时区、Open-Meteo 开源气象、内置计算器）。
- **精准匹配**：问「云南保山今天的天气」答的就是保山的实时天气，绝不拿无关资讯糊弄你。
- **实时搜索进度**：每条回答下方实时显示各引擎抓取进度与条数，点开可查看搜索了哪些网页、通过什么引擎。
- **来源可溯源**：每条回答附引用来源芯片，点击直达原网页（内置 WebView，链接自动高亮）。
- **上下文记忆**：全部对话持久保存在本地数据库，杀掉后台重进接着聊；「我上一个问题是什么」也能答上来。
- **重新回答 / 深度核查**：对答案不满意？「重新回答」换角度再来，「再查查」触发全网深度核查模式。
- **全网找图找视频**：三路图库（必应/百度/DuckDuckGo）+ 两路视频源（B站/必应视频），不满意回「换一批」；介绍类问题还会自动配图配视频帮助理解。
- **语音朗读**：系统 TTS 全文朗读，可开关。
- **流式输出**：打字机式实时呈现，答案一屏放不下自动上滑跟随。
- **快速搜索**：下拉直达任意引擎网页版，支持添加自定义引擎（`{q}` 占位）。
- **完全开源**：MIT License，仅使用开源组件（Jetpack Compose / OkHttp / Jsoup / Coil / Kotlin Coroutines），无追踪、无闭源 SDK。

## 构建

```bash
./gradlew assembleRelease
# 产物：app/build/outputs/apk/release/app-release.apk
```

要求：JDK 17+、Android SDK（compileSdk 35）。GitHub Actions 会自动完成云编译并发布 Release APK。

## 使用提示

- 引擎抓取基于公开网页，个别引擎偶尔限流属正常现象；APP 已内置 UA 轮换、浏览器指纹头、失败重试、健康度冷却（连败 3 次冷却 10 分钟）等反反爬机制，并在设置中提供 14 路引擎开关，东边不亮西边亮。
- 「实验」标记的引擎（神马/头条/抖音/秘塔/Brave）网页结构多变，成功率有限，失败不影响整体。
