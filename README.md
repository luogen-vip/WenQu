# 问渠 WenQu · 全网聚合 AI 搜索助手（内置本地大模型）

> 「问渠那得清如许，为有源头活水来。」
>
> 作者：罗根

问渠是一款 **100% 开源** 的安卓搜索问答应用。**APK 内置本地大模型（Qwen2.5-0.5B，llama.cpp 推理，离线运行）**：搜索完成后，由模型阅读全部材料、理解你的问题、实时总结成直接回答——不走固定模板、不照搬网页原文。同时实时调动多路搜索引擎并行抓取、交叉验证。

## 核心特性

- **本地大模型总结回答（v1.3 新增）**：Qwen2.5-0.5B-Instruct（Q6_K 量化，约 570MB）随 APK 离线携带，纯 CPU 推理、不上传任何数据。搜索结果先经过强相关性过滤（联想词条/广告/无关句全部剔除），再交给模型阅读理解，流式生成 2-5 句直接回答；模型不可用时自动回退到规则合成。设置里可开关。
- **回答只给答案**：问「孙悟空是谁」就回答孙悟空是谁——直接回答句优先、无关内容（相关搜索、推荐板块、其他词条）绝不混入。
- **国内直连可用的多路引擎**：必应 / 必应中国 / 百度（移动版）/ 搜狗 / 360 / 神马 / 头条，全部同时开查，单引擎限时 9 秒、连败自动冷却。
- **智能意图识别 + 澄清反问**：问时间/日期/计算本地秒答；问天气没说地点时反问「你想知道哪里的天气？」而不是乱搜；说「你好」像人一样实时回应。
- **计算带语气条件**：「用幽默的语气回答 1+1 等于多少」——本地精确算出数值，模型按指定语气润色，数值绝不改变。
- **多主体图片**：「找孙悟空和熊出没的图片」→ 多个主体并行搜索、交错展示、每张标注主体；「换一批」池化翻页不重复；推广/广告图（标题命中推广词）自动过滤。
- **上下文真正关联**：手动输入「再查一查」与点按钮一样继承上一轮话题；全部对话持久化，杀后台重进接着聊。
- **聊天位置不漂移**：从视频/图片点进网页再返回，聊天列表停在原地；离开底部出现「回到底部」悬浮箭头，一点到底。
- **视频修复**：B站改用桌面版网页直链 + WebView 加固（拦截 intent:// 等唤端 scheme、仅主帧错误才提示、自动播放、可一键换姿势重试），不再"加载一下就网页无法打开"。
- **来源可溯源**：每条回答附引用来源芯片，点击直达原网页。
- **语音朗读可停**：消息下方「朗读/停止朗读」文字按钮，播放中点击即停。
- **返回键合乎直觉**：所有二级页逐级回退；流式输出、快速搜索、自定义引擎。
- **完全开源**：MIT License，无追踪、无闭源 SDK。

## 构建

```bash
# 1. clone llama.cpp（b4589）到 app/src/main/cpp/llama
git clone --depth 1 --branch b4589 https://github.com/ggerganov/llama.cpp app/src/main/cpp/llama

# 2. 下载模型权重（Qwen2.5-0.5B-Instruct Q6_K）到 jniLibs（以 libmodel.so 名义打包）
curl -L -o app/src/main/jniLibs/arm64-v8a/libmodel.so \
  "https://huggingface.co/Qwen/Qwen2.5-0.5B-Instruct-GGUF/resolve/main/qwen2.5-0.5b-instruct-q6_k.gguf"

# 3. 编译（需要 JDK 17、Android SDK 35、NDK、CMake 3.22）
gradle assembleRelease
# 产物：app/build/outputs/apk/release/app-release.apk（约 570MB，含模型）
```

GitHub Actions 会自动完成上述全部步骤并云编译发布 Release APK。

## 技术栈

- Kotlin + Jetpack Compose / Material 3
- llama.cpp（b4589）+ JNI：本地模型推理，纯 CPU，arm64-v8a
- Qwen2.5-0.5B-Instruct-GGUF（Apache-2.0，阿里通义开源）
- OkHttp / Jsoup：多引擎抓取
- Coil：图片加载

## 使用提示

- 内置模型首次回答需要热身（加载+预热约 10-30 秒，视机型），之后每条回答在数秒到十几秒内流式生成；低内存设备加载失败会自动回退规则整理，不影响搜索功能。
- 引擎抓取基于公开网页，个别引擎偶尔限流属正常现象；单引擎最长等待 9 秒。
- 「实验」标记的引擎（神马/头条）网页结构多变，成功率有限，失败不影响整体。
