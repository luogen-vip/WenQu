# 问渠 WenQu · 全网聚合 AI 搜索助手

> 「问渠那得清如许，为有源头活水来。」
>
> 作者：罗根

问渠是一款 **100% 开源** 的安卓搜索问答应用。它不内置体积庞大的本地大模型，也不依赖任何闭源云服务——而是实时调动多路搜索引擎并行抓取、交叉验证、整理成精准简洁的回答。

## 核心特性

- **国内直连可用的多路引擎**：必应 / 必应中国 / 百度（移动版）/ 搜狗 / 360 / 神马 / 头条，全部同时开查，单引擎限时 9 秒、连败自动冷却，谁抽风就换谁上，绝不拖慢整体。
- **智能意图识别**：说「你好」「在干嘛」会像人一样动态回复，而不是去搜一堆不相关的资讯；问时间/日期/天气/计算直接本地秒答（全球时区、Open-Meteo 开源气象+地理编码、内置计算器）。
- **答案先给结论**：合成器优先抽取「直接回答问题的那句话」（定义句/主体开头句），段落化总结，不再照搬资讯列表。
- **上下文真正关联**：「给我找相关的图片」「再查查」会自动继承上一轮话题主体，不会答非所问；全部对话持久化，杀后台重进接着聊。
- **实时搜索进度**：每条回答下方实时显示各引擎抓取进度，**点引擎名可展开查看该引擎具体搜到了哪些网页**，点击条目直达。
- **全网找图找视频**：四路图库（必应/百度/搜狗/360）+ 两路视频源（B站/必应视频）；支持「找5张图」数量控制；「换一批」池化翻页不重复、不超页打叉。
- **来源可溯源**：每条回答附引用来源芯片，点击直达原网页（内置 WebView，链接自动高亮）。
- **语音朗读可停**：播放中点喇叭即停止（不是从头重播），设置里关闭立即静音。
- **返回键合乎直觉**：设置/快速搜索/网页等所有二级页，系统返回键逐级回退，抽屉打开时返回键先关抽屉。
- **流式输出**：打字机式实时呈现，答案一屏放不下自动上滑跟随。
- **快速搜索**：直达各引擎网页版，支持添加自定义引擎（`{q}` 占位）。
- **完全开源**：MIT License，仅使用开源组件（Jetpack Compose / OkHttp / Jsoup / Coil / Kotlin Coroutines），无追踪、无闭源 SDK。

## 构建

```bash
gradle assembleRelease
# 产物：app/build/outputs/apk/release/app-release.apk
```

要求：JDK 17+、Android SDK（compileSdk 35）。GitHub Actions 会自动完成云编译并发布 Release APK。

## 使用提示

- 引擎抓取基于公开网页，个别引擎偶尔限流属正常现象；APP 已内置 UA 轮换、浏览器指纹头、失败重试、健康度冷却等机制；单引擎最长等待 9 秒，超时立即标记失败继续其他引擎。
- 「实验」标记的引擎（神马/头条）网页结构多变，成功率有限，失败不影响整体。
- 被墙或需登录的引擎（DuckDuckGo / Mojeek / SearXNG / Brave / 维基百科 / 秘塔 / 抖音）已按反馈移除，保持列表干净、搜索不空转。
